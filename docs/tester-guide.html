Smart Assistant for Dolibarr — Tester Guide

Reviewer walkthrough · Module version 1.0.0 · Integmia · For reviewer use — please do not publish

1. Purpose

This guide takes you through installing, enabling and verifying Smart Assistant — a Dolibarr module that embeds an AI operations dashboard (monitoring agents, recommendations and approved actions) inside Dolibarr. Expected time: 10–15 minutes.

Before you start, confirm you have:

  • A Dolibarr instance 18+ (tested on 23.x), PHP 7.0+, reachable over HTTPS
  • Dolibarr REST API enabled with a read-only API key (Users & Groups → user → Edit → API key field)
  • The module ZIP: smartassistant-1.0.0.zip

2. Install the Module

Option A — Module installer (recommended)

  1. Log in as administrator → Setup → Modules/Applications
  2. Click Install external module (top of the page)
  3. Upload smartassistant-1.0.0.zip
  4. Smart Assistant appears in the module list

Option B — Manual (FTP)

  1. Copy the smartassistant/ folder from the ZIP to htdocs/custom/ (result: htdocs/custom/smartassistant/)
  2. Ensure files are readable by the web server (files 644, directories 755)
  3. Reload Setup → Modules/Applications

If the Modules page renders blank after uploading, the upload was truncated — re-upload, or use Option B and confirm core/modules/modSmartAssistant.class.php is present (~5.4 KB).

3. Enable the Module

  1. In Setup → Modules/Applications, find Smart Assistant
  2. Click Enable — the module activates (green status)
  3. A Smart Assistant top menu appears with Dashboard and Setup
  4. Verify permissions: Users & Groups → Permissions shows two new entries: Read Smart Assistant dashboard and Manage Smart Assistant connection

4. Connect to the Hosted Service

  1. Open Smart Assistant → Setup
  2. Fill the form:
FieldValue
Hosted service URLhttps://dolibarr.smartassistant.site
Dolibarr URL (this instance)https://your-dolibarr.example.com
Dolibarr API keythe read-only key from §1
  1. Click Connect

The Connect action performs a live verification: the hosted service calls your Dolibarr API once with the supplied key. On success the status flips to Connected.

Expected error: "Connection failed: Dolibarr rejected the API key (HTTP 401)" when the key is invalid — verify the key has no leading/trailing spaces.

5. Verify the Dashboard

  1. Open Smart Assistant → Dashboard
  2. The hosted dashboard embeds inside Dolibarr and shows:
  • Five agents (Revenue & Sales Ops, Customer Success, Procurement & Inventory, Operations Orchestration, Business Intelligence) with last-run status
  • Open Recommendations — prioritized findings with rationale
  • Pending Actions — approval workflow (human-in-the-loop)
  • Run all agents button — triggers an immediate analysis cycle

Click Run all agents: agents execute against the connected Dolibarr (read-only) and recommendations populate within a minute or two.

Acceptance: the dashboard loads, agents report ok, and at least one recommendation or action appears after a run (on a fresh instance, agents may report "nothing actionable" — that is expected behavior, not an error).

6. Disconnect / Reconnect

  • Disconnect (Setup page) removes the token from Dolibarr; the Dashboard stops loading and shows a "Not connected" notice
  • Connect again re-issues a fresh token (old tokens are invalidated server-side)
  • After reconnecting, the Dashboard works again — this is the expected lifecycle

7. Troubleshooting

SymptomLikely cause / fix
Modules page blank after uploadTruncated upload — re-upload or install via FTP (§2B)
Smart Assistant not listedFolder not at htdocs/custom/smartassistant/, or files not readable (644/755)
Connect fails, HTTP 401API key invalid — check for stray spaces; verify in the user record
Connect fails, network errorHosted service unreachable — check HTTPS egress from your server
Dashboard: "Missing or invalid token"Re-run Connect (tokens rotate on re-registration)
